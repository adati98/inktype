INKTYPE Public Beta v4.1

GitHub Pages 公開用ファイルです。

公開方法:
1. index.html / .nojekyll をリポジトリ直下へ配置
2. GitHub Desktop で変更を Commit
3. Push origin
4. GitHub Pages は main / (root) を公開元に設定

v4.1 主な変更:
- ニックネーム欄の個人名プレースホルダーを「例：イカネーム」に変更
- 画面上の内部バージョン番号を非表示化
- 「試作」表現を「参考値」に変更
- プライバシー文言をバージョン非依存に整理
- FRIEND など開発寄りの表示を日本語化
